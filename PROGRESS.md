# АКТУАЛЬНОЕ СОСТОЯНИЕ

## Что это сейчас

Telegram Mini App: жутко-сюрреалистичное медитативное приложение, не игра.
Полный путь проходится без ошибок: титул → архив → 6 сцен → смерть →
переход → космос → финал.

`npm.cmd test` — 11/11 (6 тестов физики полёта + 5 тестов каталога жизней).

## Контент

- **300 жизней**: 12 написанных вручную + 288 детерминированных архетипных.
- У каждой: имя, пол, город, год, желание, символ, 6 сцен, 3 решения,
  последняя мысль, формулировка смерти.
- `id` работает как seed и для текста, и для 16-bit рендерера.
- Пять записей в архиве собираются заново при каждом входе.
- `content.test.cjs`: ровно 300, уникальность имён, 6 сцен, 3 выбора,
  согласование фамилий по роду.

Известная слабость: сгенерированные 288 жизней читаются как заполнитель.
Для жанра 40 написанных вручную жизней сильнее, чем 300 шаблонных.

## 16-bit рендерер воспоминаний

- Кадр 480×270, два canvas (фон + персонаж).
- Цветовые рампы по 6 тонов, ordered dithering (Bayer 4×4), контур 1 px,
  rim light от окна, ambient occlusion, текстуры дерева/ткани/воды,
  световое пятно от окна.
- Персонаж маленький и внутри сцены.
- Шесть композиций: рождение, детство, поворот, голос, прощание, после.
- `pixel-lab.html` — контактный лист 300 × 6 = 1800 кадров, крупный просмотр,
  прямые ссылки `#<жизнь>-<сцена>`.

## Космос

- WebGL (three.js r160, локально) + 2D-canvas слой + резервный рендер без WebGL.
- Физика в `flight.js`: кадрово-независимая, мягкая тяга, длинный дрейф,
  торможение по «Покой».
- Адаптивное качество `high / balanced / economy` по EMA времени кадра.
- ACES filmic tone mapping, галактическая полоса, тусклые звёзды
  с перспективным размером, приглушённые туманности.
- Pacing director: длинные окна тишины, редкие тихие сигналы без остановки полёта.
- События Земли, Луны и дальнего сигнала открываются только по «Сканировать».
- HUD минимальный: имя сущности, состояние, редкий сигнал.

## Финал

- После сигнала — экран финала.
- **45 секунд тишины**: только текст и строка «не закрывай. просто побудь здесь».
- Кнопки появляются позже; «прожить другую жизнь» — последней, приглушённой строкой.

## Убрано из интерфейса (принципиально)

- `ПРОЖИТО ЖИЗНЕЙ · ЭКСПЕДИЦИЙ · ПАМЯТЬ %` из архива.
- «ОТПЕЧАТОК ПРОХОЖДЕНИЯ» с процентами.

- theme sync, viewport sync, haptics, safe-area, `100dvh`, без tap-highlight.

## Звук

WebAudio без файлов: дрон, статика, ping, whisper + процедурные cues
3–4 секунды на каждый этап жизни. Непрерывного слоя на всю сессию пока нет.

# ДАЛЬШЕ ПО ПЛАНУ

Порядок по смыслу, не по сложности:

1. **Место для ответа.** Пустая строка «твоя последняя мысль» в конце.
   Не сохраняется на сервер, не шарится.
2. **Ритуал входа.** Затухание, пауза, одна строка вместо мгновенного меню.
3. **Непрерывный звуковой слой** на всю сессию.
4. **Сюрреализм в сценах**: нарушение бытовой логики вместо буквальных комнат.
5. **Бэкенд-минимум**: Worker + проверка `initData` + анонимная воронка.
6. **Модуляризация**: разнести `app.js`, контент в JSON, Vite.
7. **Ежедневный ритм**: одна новая жизнь в сутки.
