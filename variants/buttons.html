Варианты кнопки «Войти в архив»

выберите один — остальные удалю
1. Выцветшая печать
Двойная рамка с неровным краем. При нажатии короткая вспышка, как у старого терминала.
2. Пульс сердцебиения
Тусклая рамка. Раз в несколько секунд по ней проходит красноватый импульс и текст дёргается.
3. Сдвиг строк
Тёмная плашка с развёрткой. При наведении текст раздваивается, как помехи записи.
4. Текст, который тает
Без рамки и фона. При наведении надпись стирается, при нажатии медленно гаснет.
5. Надпись-приглашение
Одна строка с мигающим курсором, будто ввод в пустой терминал.
