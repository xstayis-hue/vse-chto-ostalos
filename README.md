# Всё, что от меня ОСТАЛОСЬ

Независимая браузерная вертикальная демоверсия концепта Telegram Mini App.

## Запуск

Откройте `index.html` через любой статический сервер. Проект не требует зависимостей или сборки.

## Игровой путь

Стартовый архив → выбор жизни → пять фрагментов жизни → смерть → космос → сигнал → финальный выбор.

## Управление

На космическом экране используются кнопки скорости, фокусировки и интерактивный круг управления. Демо работает в мобильном браузере и не требует Telegram API.
