# Всё, что от меня ОСТАЛОСЬ

Медитативный браузерный миниапп: собственная случайная жизнь, увиденная со стороны в воспоминаниях, отделение сознания и свободный полёт в космосе.

## Запуск

Откройте проект через локальный статический сервер (например, `npx serve .` или расширение Live Server в VS Code). Открытие `index.html` напрямую (`file://`) блокирует текстуры WebGL в большинстве браузеров. Проект не требует зависимостей или сборки.

## Путь

«Вспомнить» → одна из 500 жизней → шесть воспоминаний → отделение сознания → бесцельный полёт. В активном пути нет задач, коллекций и обязательного финального выбора. Цитаты Иисуса сохранены.

## Управление

Свайп или перетаскивание неба — взгляд; круг слева или WASD/стрелки — тяга; «Покой» — мягкое торможение. «Прислушаться» — необязательная тихая мысль. Можно выключить звук и вернуться на титул. Полёт сохраняет позицию каждые пять секунд, при сворачивании и выходе.

## Бесплатный генератор воспоминаний

`memory-world.js` работает локально, без ключей и платных API. `describe()` компилирует 3000 воспроизводимых описаний из 500 биографий. Seed жизни задаёт палитру одежды, волосы и пропорции; этап задаёт возраст, локацию, свет, погоду, положение и предмет.

Canvas собирает кадр из локальных фотографических сред и хромакейных фигур, удаляет зелёный фон, меняет одежду, выполняет компоновку и плёночную обработку. Это комбинационный генератор, а не локальная нейросеть: исходные комнаты и фигуры могут повторяться. При отсутствии исходной среды предусмотрен процедурный Three.js-рендер 16 типов локаций. Кэш ограничен десятью готовыми кадрами.

`memory-studio.html` — локальная мастерская: выбор любой жизни, просмотр всех шести кадров, сравнение трёх жизней. Генерация исходных ассетов через API выполнялась только при разработке; инструменты в `tools/` не подключены к приложению.

## Проверки

`npm test` (Windows PowerShell: `npm.cmd test`) проверяет контент, физику, 3000 описаний сцен, постоянство параметров человека и fallback перехода без WebGL.

## Сохранение и офлайн

Состояние хранится только в localStorage устройства. Сервер аккаунтов не требуется. На HTTPS service worker кэширует оболочку и просмотренные ресурсы для повторного открытия; первый запуск и ещё не загруженные картинки требуют сети. На localhost service worker отключён для разработки.
